\section*{2. Capaian Pembelajaran Lulusan (CPL)}

CPL yang dibebankan pada mata kuliah ini adalah sebagai berikut:

\begin{itemize}[leftmargin=*]
  \item \textbf{CPL02:} Memiliki pengetahuan yang memadai terkait dengan cara kerja sistem komputer dan mampu merancang dan mengembangkan berbagai algoritma metode untuk memecahkan masalah.

  \item \textbf{CPL03:} Kemampuan merancang dan menganalisis algoritma untuk menyelesaikan permasalahan organisasi secara optimal, serta memilih dan menerapkannya pada bahasa pemrograman tertentu.
\end{itemize}

\vspace{0.3cm}

\textbf{Keterkaitan CPL dengan Mata Kuliah:}
\begin{itemize}[leftmargin=*]
  \item CPL02 didukung melalui pemahaman cara kerja mikroprosesor 8086 pada level mesin: pembagian \textit{Bus Interface Unit} dan \textit{Execution Unit}, register, organisasi memori bersegmen, serta mekanisme interupsi.
  \item CPL03 didukung melalui perancangan dan penulisan program assembly untuk operasi aritmatika, logika, percabangan, perulangan, prosedur, dan pengolahan data, kemudian diuji serta diperbaiki melalui penelusuran per instruksi.
\end{itemize}

\section*{6. Metode Pembelajaran}

Strategi pembelajaran dipilih sesuai OBE dengan penekanan pada aktivitas mahasiswa:

\begin{itemize}[leftmargin=*]
  \item \textbf{Ceramah Interaktif:} penjelasan arsitektur, instruksi, dan contoh kode dari buku sumber.
  \item \textbf{Praktikum Terbimbing:} mahasiswa menulis berkas \texttt{.ASM}, meng-compile dengan TASM, men-link dengan TLINK, lalu menjalankan program.
  \item \textbf{Latihan Terstruktur:} mengerjakan contoh program pada buku, kemudian memodifikasi operand, instruksi, atau alurnya.
  \item \textbf{Pembelajaran Berbasis Proyek Kecil:} menyusun program COM/EXE untuk kasus aritmatika, logika, pengolahan array/string, atau antarmuka teks.
  \item \textbf{Review Kode Berpasangan:} memeriksa program secara berpasangan dan mencatat kesalahan sintaks maupun logika.
  \item \textbf{Diskusi dan Presentasi:} membahas hasil praktikum dan cara memperbaiki program.
\end{itemize}

\textbf{Lingkungan Pembelajaran:}
\begin{itemize}[leftmargin=*]
  \item Editor teks untuk berkas \texttt{.ASM} (sesuai [1] Bagian 4.1).
  \item DOSBox dengan TASM, TLINK, dan DEBUG untuk alur tutorial S'to (sesuai [2] BAB V dan [1] Bagian 4.2).
  \item emu8086 untuk menulis, menjalankan, dan men-debug program (sesuai [1] Bagian 4.3).
  \item Turbo Debugger untuk menelusuri program per instruksi (sesuai [2] BAB XXVII).
\end{itemize}

\section*{7. Pengalaman Belajar Mahasiswa}

Deskripsi tugas, aktivitas, dan pengalaman belajar yang mendukung pencapaian Sub-CPMK:

\begin{itemize}[leftmargin=*]
  \item Mengonversi bilangan biner, desimal, oktal, dan heksadesimal serta menuliskan bentuk bilangan yang diterima assembler.
  \item Menghitung alamat fisik dari pasangan \textit{segment:offset} secara manual dan memeriksanya dengan DEBUG.
  \item Menulis, meng-assemble, dan men-link program \texttt{.ASM} menjadi berkas \texttt{.COM} atau \texttt{.EXE}.
  \item Menulis program dengan instruksi transfer data, aritmatika, dan logika.
  \item Menyusun program bercabang dan berulang menggunakan CMP, JMP, lompatan bersyarat, dan LOOP.
  \item Membuat prosedur dan macro untuk memecah program menjadi bagian-bagian kecil.
  \item Mengolah array dan string serta mencetak bilangan desimal dan heksadesimal ke layar.
  \item Menggunakan interupsi BIOS/DOS untuk mencetak karakter/kalimat, mengatur layar, dan membaca masukan keyboard.
  \item Menelusuri program per instruksi dan memeriksa register, flag, memori, serta stack untuk menemukan kesalahan.
  \item Menyusun laporan praktikum yang memuat kode, hasil eksekusi, dan analisis kesalahan.
\end{itemize}

\textbf{Proyek Akhir:}
\begin{itemize}[leftmargin=*]
  \item Pilihan 1: program kalkulator bilangan dengan ADD, SUB, MUL, dan DIV.
  \item Pilihan 2: program pengolahan array atau string (pencarian dan pencetakan data).
  \item Pilihan 3: program konversi dan pencetakan bilangan desimal serta heksadesimal.
  \item Pilihan 4: program menu teks dengan interupsi BIOS/DOS.
\end{itemize}

\section*{9. Evaluasi dan Refleksi Pembelajaran}

Penilaian formatif dan sumatif untuk memantau ketercapaian \textit{outcome} secara menyeluruh:

\begin{itemize}[leftmargin=*]
  \item \textbf{Evaluasi Formatif:} kuis, latihan \textit{coding}, pemeriksaan program dengan DEBUG, dan umpan balik per pertemuan.
  \item \textbf{Evaluasi Sumatif:} UTS dan UAS untuk mengukur pencapaian CPMK.
  \item \textbf{Refleksi Mahasiswa:} jurnal praktikum yang mencatat kesalahan sintaks/logika dan cara memperbaikinya.
  \item \textbf{Review Kode:} pembahasan bersama atas program yang belum berjalan benar dan alternatif perbaikannya.
  \item \textbf{Evaluasi Dosen:} peninjauan kesesuaian materi, contoh program, dan alokasi waktu praktikum.
  \item \textbf{Perbaikan Berkelanjutan:} analisis hasil tugas, praktikum, dan proyek untuk penyempurnaan bahan kajian.
\end{itemize}

\textbf{Monitoring Progres:}
\begin{itemize}[leftmargin=*]
  \item Pemeriksaan berkas \texttt{.ASM} dan hasil \textit{compile}/\textit{link} setiap minggu.
  \item Pemeriksaan hasil penelusuran register, memori, dan stack pada praktikum debugging.
  \item Pemantauan progres proyek akhir melalui laporan antara.
  \item Penilaian sejawat pada kegiatan review kode berpasangan.
\end{itemize}
