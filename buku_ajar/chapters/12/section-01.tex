\section{Operand dan Tiga Mode Dasar}
\label{sec:mode-dasar}

Sebelum mengeksekusi instruksi, prosesor harus mengetahui di mana
operand berada. Data dapat berada di dalam instruksi, di dalam
register, atau di dalam memori pada alamat tertentu. Cara prosesor
menyatakan letak operand disebut \term{mode pengalamatan}
(\eng{addressing mode}).

Bagian ini diringkas dari \cite{gunawan2019}, Bagian 9,
hlm.~78--92, dan \cite{sto2001}, BAB XI, hlm.~52--62.

\subsection{Operand Sumber dan Tujuan}

Sebagian besar instruksi 8086 memakai dua operand: operand sumber
dan operand tujuan. Instruksi \lstasm|MOV AX, BX| memindahkan isi
\reg{BX} ke \reg{AX}. Operand tujuan harus berupa tempat yang dapat
menampung hasil, yaitu register atau lokasi memori. Nilai segera
tidak dapat menjadi tujuan.

Mode pengalamatan menentukan bagaimana operand ditulis dan bagaimana
prosesor memperoleh nilainya. Tujuh mode yang dipakai pada bab ini
dirangkum pada Tabel~\ref{tab:tujuh-mode}.

\subsection{Mode Register}

Pada mode \term{register}, operand berada di dalam register. Baik
sumber maupun tujuan berupa register, tanpa pengaksesan memori.

\begin{lstlisting}[language=MASM, numbers=none]
MOV AX, BX          ; AX <- BX
ADD DX, CX          ; DX <- DX + CX
MOV DL, AL          ; DL <- AL (ukuran harus sama)
\end{lstlisting}

Mode ini paling cepat dan paling ringkas karena seluruh operasi
berlangsung di dalam prosesor. Keterbatasannya adalah jumlah register
8086 yang sedikit.

\subsection{Mode Immediate}

Pada mode \term{immediate}, operand sumber adalah nilai konstan yang
sudah tertulis di dalam instruksi. Nilai itu tidak disimpan di
memori, sehingga prosesor tidak perlu mengakses memori untuk
mengambilnya.

\begin{lstlisting}[language=MASM, numbers=none]
MOV AX, 1234h       ; AX <- 1234h (immediate 16 bit)
MOV BL, 0Ah         ; BL <- 0Ah (immediate 8 bit)
ADD CX, 100         ; CX <- CX + 100
MOV AL, 'A'         ; AL <- 41h, kode ASCII 'A'
\end{lstlisting}

Ukuran nilai segera mengikuti ukuran register tujuan: 8 bit untuk
\reg{AL} dan 16 bit untuk \reg{AX}. Nilai segera dipakai untuk
mengisi nilai awal atau menaikkan nilai dengan langkah tetap.

\subsection{Mode Direct Memory}

Pada mode \term{direct memory}, operand berada di memori dan
alamatnya (offset) ditulis di dalam instruksi. Assembler menggantikan
nama variabel dengan offset yang sebenarnya.

\begin{lstlisting}[language=MASM, numbers=none]
.DATA
    nilai   DW 1234h
    total   DW ?

.CODE
    MOV AX, nilai       ; AX <- isi memori DS:nilai
    MOV AX, [1234h]     ; AX <- isi memori pada offset 1234h
    MOV total, AX       ; simpan AX ke variabel total
\end{lstlisting}

Alamat pada mode ini tetap karena tertulis di dalam instruksi.
Mode ini cocok untuk variabel tunggal seperti pencacah atau bendera.

\begin{peringatanbox}
\vspace{1.1em}
Dua penulisan berikut tampak mirip, tetapi artinya berbeda.
\lstasm|MOV AX, nilai| menyalin \emph{isi} variabel \code{nilai}
(mode direct), sedangkan \lstasm|MOV AX, OFFSET nilai| menyalin
\emph{offset}-nya sebagai nilai segera. Hal serupa berlaku pada
\lstasm|MOV AX, 1234h| (nilai) dan \lstasm|MOV AX, [1234h]| (isi
memori).
\end{peringatanbox}
