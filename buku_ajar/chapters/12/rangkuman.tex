\section{Rangkuman}
\label{sec:rangkuman-bab12}

Pada bab ini telah dibahas:

\begin{itemize}
    \item Mode pengalamatan adalah cara prosesor menyatakan letak
          operand: di dalam instruksi, di register, atau di memori.

    \item Tujuh mode pengalamatan 8086 adalah \textit{register},
          \textit{immediate}, \textit{direct memory}, \textit{indirect
          memory}, \textit{base relative}, \textit{direct index}, dan
          \textit{based indexed}.

    \item Mode \textit{register} dan \textit{immediate} tidak
          mengakses memori. Mode \textit{direct memory} memakai
          alamat tetap yang ditulis di dalam instruksi.

    \item Mode \textit{indirect memory} memakai satu register
          penunjuk: \reg{BX}, \reg{BP}, \reg{SI}, atau \reg{DI}.

    \item Mode \textit{base relative} memakai basis ditambah
          perpindahan, sedangkan \textit{direct index} memakai indeks
          ditambah perpindahan.

    \item Mode \textit{based indexed} memakai satu basis, satu indeks,
          dan satu perpindahan. Kombinasi yang legal adalah
          \code{[BX+SI]}, \code{[BX+DI]}, \code{[BP+SI]}, dan
          \code{[BP+DI]}, masing-masing dengan perpindahan opsional.

    \item Alamat efektif dihitung sebagai basis ditambah indeks
          ditambah perpindahan. Alamat fisik dibentuk dengan
          menambahkan basis segmen.

    \item Segmen default adalah \reg{DS} untuk \reg{BX}, \reg{SI},
          dan \reg{DI}, serta \reg{SS} untuk \reg{BP}. Segmen dapat
          diganti dengan penulisan seperti \lstasm|ES:[BX]|.
\end{itemize}

\begin{checklistbox}
\vspace{1.1em}
Tandai setiap butir yang sudah Anda kuasai.

\begin{itemize}
    \item[\checkbox] Saya dapat menjelaskan pengertian mode
          pengalamatan.
    \item[\checkbox] Saya dapat menyebutkan tujuh mode pengalamatan
          8086.
    \item[\checkbox] Saya dapat membedakan mode \textit{direct} dan
          \textit{indirect}.
    \item[\checkbox] Saya dapat menggunakan \textit{base relative}
          dan \textit{direct index}.
    \item[\checkbox] Saya dapat menggunakan \textit{based indexed}
          dengan kombinasi register yang legal.
    \item[\checkbox] Saya dapat menghitung alamat efektif dan alamat
          fisik.
    \item[\checkbox] Saya dapat menentukan segmen default setiap mode.
\end{itemize}

\vspace{0.4em}
Bila masih ada butir yang belum bertanda, ulangi bagian yang
bersesuaian sebelum melanjutkan ke bab berikutnya.
\end{checklistbox}
