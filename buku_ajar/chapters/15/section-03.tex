\section{Mencetak Bilangan Desimal dan Heksadesimal}
\label{sec:cetak-bilangan}

Nilai di dalam register selalu berbentuk biner, sedangkan layanan DOS
fungsi \hex{02} hanya mencetak satu karakter pada satu waktu. Program
karena itu harus mengubah bilangan menjadi deret digit, lalu mengubah
setiap digit menjadi kode ASCII.

Bagian ini diringkas dari \cite{gunawan2019}, Bagian 14.1,
hlm.~127--131, dan \cite{sto2001}, BAB XX, hlm.~117--121.

\subsection{Konversi ke Digit Desimal}

Algoritme konversi desimal:

\begin{enumerate}
    \item bagi bilangan dengan 10;
    \item simpan sisa pembagian sebagai satu digit;
    \item ulangi sampai hasil bagi nol;
    \item ambil digit dari yang terakhir disimpan, lalu cetak.
\end{enumerate}

Sisa pembagian harus disimpan sementara pada \eng{stack} agar urutan
cetaknya terbalik menjadi benar.

\begin{lstlisting}[language=MASM, numbers=none]
CETAK_DESIMAL PROC
    PUSH AX
    PUSH BX
    PUSH CX
    PUSH DX

    MOV CX, 0
    MOV BX, 10
BAGI:
    XOR DX, DX
    DIV BX              ; AX = hasil bagi, DX = sisa
    PUSH DX             ; simpan digit
    INC CX
    CMP AX, 0
    JNE BAGI

CETAK_DIGIT:
    POP DX
    ADD DL, '0'         ; digit -> karakter ASCII
    MOV AH, 02h
    INT 21h
    LOOP CETAK_DIGIT

    POP DX
    POP CX
    POP BX
    POP AX
    RET
CETAK_DESIMAL ENDP
\end{lstlisting}

\subsection{Konversi ke Digit Heksadesimal}

Heksadesimal memakai empat bit per digit. Digit diambil dengan
menggeser empat bit ke kiri berulang kali, lalu menyaring empat bit
terendah dengan \asm{AND} \hex{0F}.

\begin{lstlisting}[language=MASM, numbers=none]
CETAK_HEX PROC
    PUSH AX
    PUSH BX
    PUSH CX
    PUSH DX

    MOV CX, 4
HEX_ULANG:
    ROL AX, 4
    MOV DL, AL
    AND DL, 0Fh
    CMP DL, 9
    JBE HEX_ANGKA
    ADD DL, 7           ; 0Ah..0Fh -> 'A'..'F'
HEX_ANGKA:
    ADD DL, '0'
    MOV AH, 02h
    INT 21h
    LOOP HEX_ULANG

    POP DX
    POP CX
    POP BX
    POP AX
    RET
CETAK_HEX ENDP
\end{lstlisting}

\begin{infobox}
\vspace{1.1em}
Untuk bilangan nol, perulangan pembagian tetap dijalankan sekali
sehingga satu digit \code{'0'} tersimpan dan dicetak. Tanpa langkah
itu, program dapat mencetak string kosong.
\end{infobox}

\begin{peringatanbox}
\vspace{1.1em}
Prosedur pencetakan memakai \reg{AX}, \reg{BX}, \reg{CX}, dan
\reg{DX}. Simpan register tersebut dengan \asm{PUSH} di awal dan
pulihkan dengan \asm{POP} di akhir agar nilai pemanggil tidak rusak.
\end{peringatanbox}
