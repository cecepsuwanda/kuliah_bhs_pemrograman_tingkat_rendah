\section{Array Satu dan Multi Dimensi}
\label{sec:array}

Array adalah kumpulan data bertipe sama yang disimpan berurutan di
memori. Bahasa assembly tidak menyediakan sintaks array seperti bahasa
tingkat tinggi; array dibentuk dari deklarasi data dan diakses melalui
alamat serta register indeks.

Bagian ini diringkas dari \cite{gunawan2019}, Bagian 10,
hlm.~93--100, dan \cite{sto2001}, BAB IX, hlm.~41--46.

\subsection{Array Satu Dimensi}

Array satu dimensi dideklarasikan dengan \dir{DB}, \dir{DW}, atau
\dir{DD}, lalu diisi nilai yang dipisahkan koma.

\begin{lstlisting}[language=MASM, numbers=none]
deret   DW 10, 20, 30, 40, 50
BANYAK  EQU ($ - deret) / 2      ; banyak elemen word
\end{lstlisting}

Setiap elemen word menempati dua byte. Elemen pertama berada pada
offset \code{deret}, elemen kedua pada \code{deret+2}, dan seterusnya.
Susunan ini ditunjukkan pada Gambar~\ref{fig:array-memori}.

\begin{figure}[H]
    \centering

    \end{tikzpicture}

    relatif terhadap alamat awal \code{deret}.}
    \label{fig:array-memori}
\end{figure}

Elemen array diakses dengan register penunjuk. Pola penjumlahan array:

\begin{lstlisting}[language=MASM, numbers=none]
LEA SI, deret
MOV CX, BANYAK
XOR AX, AX
JUMLAH:
    ADD AX, [SI]
    ADD SI, 2
    LOOP JUMLAH
\end{lstlisting}

\reg{SI} menunjuk elemen saat ini. Setiap iterasi menambahkan dua
karena satu elemen word berukuran dua byte.

\subsection{Array Multi Dimensi}

Array multi dimensi disimpan sebagai array satu dimensi dengan urutan
baris demi baris. Untuk matriks dengan \code{BARIS} baris dan
\code{KOLOM} kolom, elemen pada baris $r$ dan kolom $c$ berada pada
offset:

\[
    \text{offset} = (r \times \text{KOLOM} + c) \times
    \text{ukuran elemen}.
\]

Contoh matriks word $3 \times 4$:

\begin{lstlisting}[language=MASM, numbers=none]
matriks DW 1, 2, 3, 4
        DW 5, 6, 7, 8
        DW 9,10,11,12

; akses matriks[1][2] (baris 1, kolom 2)
MOV AX, 1
MOV BX, 4           ; KOLOM = 4
MUL BX              ; AX = baris x KOLOM
ADD AX, 2           ; tambah kolom
SHL AX, 1           ; kali 2 karena word
LEA SI, matriks
ADD SI, AX
MOV AX, [SI]        ; AX = 7
\end{lstlisting}

\begin{infobox}
\vspace{1.1em}
Array multi dimensi tidak memiliki struktur khusus di memori.
Prosesor hanya melihat deretan byte. Perhitungan baris dan kolom
dilakukan oleh program sebelum alamat diakses.
\end{infobox}
