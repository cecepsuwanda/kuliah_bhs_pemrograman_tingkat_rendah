\section{LEA, LDS/LES, XCHG, dan CMP}
\label{sec:lea-lds-xchg-cmp}

Selain \asm{MOV}, 8086 menyediakan instruksi transfer data yang
berfungsi khusus: mengambil alamat, memuat \eng{far pointer},
menukar isi operand, dan membandingkan dua nilai. Bagian ini
membahas keempatnya.

Pembahasan diringkas dari \cite{gunawan2019}, Bagian 5,
hlm.~35--44.

\subsection{LEA: Load Effective Address}

\asm{LEA} menyalin \emph{alamat offset} sebuah operand ke register
tujuan, bukan isi operand tersebut.

\begin{center}
\lstasm|LEA tujuan, sumber|
\end{center}

Contoh:

\begin{lstlisting}[language=MASM, numbers=none]
LEA SI, nilai       ; SI = offset variabel nilai
MOV DI, OFFSET nilai ; DI = offset variabel nilai
\end{lstlisting}

Kedua instruksi di atas menghasilkan nilai yang sama, yaitu offset
variabel \code{nilai}. Perbedaannya, \asm{LEA} mengambil alamat
secara langsung, sedangkan \lstasm|MOV ..., OFFSET ...| memakai
operator \code{OFFSET} yang dihitung assembler.

\asm{LEA} berguna ketika alamat baru diketahui saat program
berjalan, misalnya alamat elemen array yang dihitung dari register
indeks. Instruksi ini tidak mengubah \eng{flag}.

\subsection{LDS dan LES: Memuat Far Pointer}

\eng{Far pointer} adalah alamat lengkap yang terdiri atas offset dan
segmen. Di memori, far pointer menempati empat byte: dua byte offset
diikuti dua byte segmen.

\begin{itemize}
    \item \lstasm|LDS tujuan, sumber| memuat offset ke register
          tujuan dan segmen ke \reg{DS}.
    \item \lstasm|LES tujuan, sumber| memuat offset ke register
          tujuan dan segmen ke \reg{ES}.
\end{itemize}

Susunan far pointer ditunjukkan pada Gambar~\ref{fig:far-pointer}.

Contoh pemakaian:

\begin{lstlisting}[language=MASM, numbers=none]
ptr DD 12345678h    ; di memori: 78h, 56h, 34h, 12h

LDS SI, ptr         ; SI = 5678h, DS = 1234h
LES DI, ptr         ; DI = 5678h, ES = 1234h
\end{lstlisting}

\begin{peringatanbox}
\vspace{1.1em}
\asm{LDS} mengubah \reg{DS}. Setelah instruksi ini dijalankan,
variabel pada segmen data lama tidak dapat diakses sampai \reg{DS}
dikembalikan. Karena itu, \asm{LES} lebih aman untuk mengambil far
pointer bila program masih membutuhkan \reg{DS}.
\end{peringatanbox}

\subsection{XCHG: Menukar Isi Operand}

\asm{XCHG} menukar isi dua operand. Berbeda dengan \asm{MOV} yang
menyalin, \asm{XCHG} membuat kedua operand bertukar nilai.

\begin{center}
\lstasm|XCHG operand1, operand2|
\end{center}

\begin{lstlisting}[language=MASM, numbers=none]
MOV AX, 1234h
MOV BX, 5678h
XCHG AX, BX         ; AX = 5678h, BX = 1234h
\end{lstlisting}

Operand \asm{XCHG} dapat berupa register atau memori, tetapi tidak
keduanya memori sekaligus. Nilai segera tidak dapat menjadi operand
\asm{XCHG}.

\subsection{CMP: Membandingkan Dua Operand}

\asm{CMP} membandingkan dua operand dengan cara mengurangkan operand
pertama dengan operand kedua. Hasil pengurangan tidak disimpan;
yang berubah hanya \eng{flag}.

\begin{center}
\lstasm|CMP operand1, operand2|
\end{center}

\begin{lstlisting}[language=MASM, numbers=none]
MOV AX, 1234h
MOV BX, 5678h
CMP AX, BX          ; AX - BX, hasil tidak disimpan
\end{lstlisting}

Setelah \asm{CMP}, program dapat memeriksa \eng{flag} untuk
menentukan keputusan. Jika hasilnya nol, \flag{ZF} bernilai 1. Jika
operand pertama lebih kecil secara tidak bertanda, \flag{CF}
bernilai 1. Pembahasan lompatan bersyarat dilakukan pada bab tentang
percabangan dan perulangan.
