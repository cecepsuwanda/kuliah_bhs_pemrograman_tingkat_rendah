\section{Macro}
\label{sec:macro}

Macro adalah cara lain untuk memecah program menjadi bagian kecil.
Berbeda dari prosedur, macro tidak dipanggil dengan \asm{CALL}.
Assembler menyalin isi macro ke tempat macro tersebut dipakai pada
saat perakitan. Karena itu, macro dapat menerima parameter dengan
lebih mudah, tetapi ukuran program menjadi lebih besar bila macro
dipakai berkali-kali.

Bagian ini diringkas dari \cite{gunawan2019}, Bagian 13.2,
hlm.~121--126, dan \cite{sto2001}, BAB XVII, hlm.~88--92.

\subsection{Mendefinisikan Macro}

Bentuk umum macro:

\begin{lstlisting}[language=MASM, numbers=none]
NamaMacro MACRO parameter1, parameter2
    ; isi macro
ENDM
\end{lstlisting}

Setelah didefinisikan, macro dipakai dengan menuliskan namanya
beserta argumen:

\begin{lstlisting}[language=MASM, numbers=none]
NamaMacro nilai1, nilai2
\end{lstlisting}

Contoh macro untuk mencetak satu karakter sebanyak tiga kali:

\begin{lstlisting}[language=MASM, numbers=none]
Cetak_Kar MACRO Kar
    MOV CX, 3
    MOV AH, 02h
    MOV DL, Kar
Ulang:
    INT 21h
    LOOP Ulang
ENDM
\end{lstlisting}

Pemakaiannya:

\begin{lstlisting}[language=MASM, numbers=none]
Cetak_Kar 'S'       ; assembler menyalin isi macro dengan Kar = 'S'
\end{lstlisting}

\subsection{Parameter Macro}

Parameter macro diganti secara tekstual oleh assembler. Pada contoh
di atas, setiap kemunculan \code{Kar} diganti dengan \code{'S'}
sebelum program dirakit. Karena itu, macro dapat menerima karakter,
angka, nama variabel, atau register sebagai argumen.

Parameter macro berbeda dari parameter prosedur. Prosedur tidak
memiliki daftar parameter pada \asm{PROC}; data disampaikan melalui
register, stack, atau variabel. Macro memiliki daftar parameter
langsung pada definisinya.

\begin{peringatanbox}
\vspace{1.1em}
Bila macro berisi label dan dipakai lebih dari sekali, label yang
sama akan muncul berulang setelah penyalinan. Assembler dapat
melaporkan \file{Symbol already defined}. Hindari label di dalam
macro, atau pastikan setiap pemakaian menghasilkan label yang unik.
\end{peringatanbox}

\begin{infobox}
\vspace{1.1em}
Pilih prosedur bila program menekankan ukuran dan modularitas.
Pilih macro bila bagian tersebut pendek, sering dipakai, dan
parameter tekstualnya membuat penulisan lebih ringkas.
\end{infobox}
