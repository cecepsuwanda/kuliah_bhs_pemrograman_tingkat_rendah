\section{Latihan}
\label{sec:latihan-bab13}

\begin{enumerate}
    \item \textbf{Label.} Jelaskan aturan penulisan label. Mengapa
          label pada definisi memakai titik dua, sedangkan pada
          instruksi lompatan tidak?

    \item \textbf{JMP dan Jcc.} Jelaskan perbedaan \asm{JMP} dan
          lompatan bersyarat \asm{Jcc}. Kapan masing-masing dipakai?

    \item \textbf{CMP.} Jelaskan cara kerja \asm{CMP}. Mengapa
          instruksi ini tidak mengubah isi operand, tetapi dapat
          dipakai untuk mengambil keputusan?

    \item \textbf{Jcc bertanda dan tak bertanda.} Setelah
          \lstasm|CMP AX, BX|, tentukan lompatan yang tepat untuk:
          \begin{enumerate}
              \item \reg{AX} lebih besar dari \reg{BX} (bertanda);
              \item \reg{AX} lebih kecil dari \reg{BX} (tidak
                    bertanda);
              \item \reg{AX} sama dengan \reg{BX}.
          \end{enumerate}

    \item \textbf{if--else.} Terjemahkan pola berikut ke assembly.
          \begin{lstlisting}[language=MASM, numbers=none]
if (AX == BX) {
    hasil = 1;
} else {
    hasil = 0;
}
          \end{lstlisting}

    \item \textbf{LOOP.} Jelaskan cara kerja \asm{LOOP}. Apa yang
          terjadi bila \reg{CX} bernilai nol sebelum perulangan
          dimulai? Bagaimana cara mencegahnya?

    \item \textbf{Perulangan bersarang.} Mengapa pencacah luar perlu
          disimpan sebelum perulangan dalam dimulai? Di mana nilai
          itu biasanya disimpan?

    \item \textbf{Analisis program.} Pada \file{loop-maksimum.asm},
          jelaskan peran \asm{JAE}. Pada \file{bubble-sort.asm},
          jelaskan peran \asm{JBE} dan perulangan bersarang.
\end{enumerate}

\begin{refleksibox}
\vspace{1.1em}
Jawab pertanyaan berikut pada jurnal praktikum Anda.
\begin{enumerate}
    \item Bagian mana yang paling sulit Anda telusuri: pemilihan
          \asm{Jcc}, perulangan \asm{LOOP}, atau perulangan
          bersarang? Mengapa?
    \item Setelah menelusuri program, apakah Anda dapat menjelaskan
          mengapa hasil percabangan berbeda untuk bilangan bertanda
          dan tidak bertanda? Jelaskan.
    \item Konsep apa yang perlu Anda ulangi sebelum mempelajari
          stack dan prosedur pada bab berikutnya?
\end{enumerate}
\end{refleksibox}
