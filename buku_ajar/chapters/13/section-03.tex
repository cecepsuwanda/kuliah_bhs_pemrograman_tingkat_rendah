\section{Perulangan}
\label{sec:perulangan}

Perulangan adalah percabangan yang kembali ke titik awal selama
syarat tertentu terpenuhi. Prosesor 8086 menyediakan instruksi
\asm{LOOP} yang memakai register \reg{CX} sebagai pencacah.

\subsection{Instruksi LOOP}

\asm{LOOP} mengurangi \reg{CX} dengan satu, lalu melompat ke label
tujuan bila \reg{CX} belum nol.

\begin{center}
\lstasm|LOOP tujuan|
\end{center}

\begin{lstlisting}[language=MASM, numbers=none]
MOV CX, 5           ; ulangi lima kali
ULANG:
    ; badan perulangan
    LOOP ULANG      ; CX := CX - 1; lompat bila CX <> 0
\end{lstlisting}

Karena pengujian dilakukan setelah pengurangan, badan perulangan
selalu dijalankan paling sedikit satu kali. Bila \reg{CX} bernilai
nol pada awal perulangan, \asm{LOOP} akan mengulang sebanyak
65.536 kali. Karena itu, periksa \reg{CX} dengan \asm{JCXZ} bila
cacah perulangan mungkin nol.

Perulangan juga dapat dibentuk dengan \asm{DEC} dan \asm{JNZ}:

\begin{lstlisting}[language=MASM, numbers=none]
MOV CX, 5
ULANG2:
    ; badan perulangan
    DEC CX
    JNZ ULANG2      ; ulangi bila CX belum nol
\end{lstlisting}

Kedua bentuk setara. \asm{LOOP} lebih ringkas, sedangkan pasangan
\asm{DEC} dan \asm{JNZ} lebih luwes karena pencacah tidak harus
\reg{CX}.

\subsection{Pola while dan for}

Perulangan \code{while} memeriksa syarat sebelum badan perulangan.
Bila syarat tidak terpenuhi, badan tidak dijalankan sama sekali.

\begin{lstlisting}[language=MASM, numbers=none]
; while (AX < 10) { AX = AX + 1 }
ULANG_WHILE:
    CMP AX, 10
    JGE SELESAI_WHILE
    INC AX
    JMP ULANG_WHILE
SELESAI_WHILE:
\end{lstlisting}

Perulangan \code{for} dengan cacah tetap lebih ringkas memakai
\asm{LOOP}:

\begin{lstlisting}[language=MASM, numbers=none]
; for (CX = 8; CX > 0; CX--) { proses }
MOV CX, 8
ULANG_FOR:
    ; badan perulangan
    LOOP ULANG_FOR
\end{lstlisting}

\subsection{Perulangan Bersarang}

Perulangan bersarang memerlukan dua pencacah. Karena \asm{LOOP}
selalu memakai \reg{CX}, pencacah luar harus disimpan sementara
sebelum perulangan dalam dimulai. Penyimpanan tersebut biasanya
memakai \eng{stack} dengan \asm{PUSH} dan \asm{POP}.

\begin{lstlisting}[language=MASM, numbers=none]
MOV CX, 3           ; pencacah luar
LUAR:
    PUSH CX         ; simpan pencacah luar
    MOV CX, 4       ; pencacah dalam
DALAM:
    ; badan perulangan dalam
    LOOP DALAM
    POP CX          ; pulihkan pencacah luar
    LOOP LUAR
\end{lstlisting}

Pola ini dipakai pada pengurutan gelembung: perulangan luar
menentukan banyak lintasan, perulangan dalam membandingkan pasangan
elemen yang berdekatan.

\subsection{Contoh Pola: Nilai Maksimum}

Pola pencarian nilai maksimum memakai \asm{CMP} dan \asm{JAE}.
Kandidat maksimum disimpan di \reg{AX}; setiap elemen dibandingkan
dengan kandidat.

\begin{lstlisting}[language=MASM, numbers=none]
LEA SI, deret
MOV CX, BANYAK - 1
MOV AX, [SI]
ADD SI, 2
CARI:
    CMP AX, [SI]
    JAE LANJUT          ; kandidat >= elemen: tidak diganti
    MOV AX, [SI]
LANJUT:
    ADD SI, 2
    LOOP CARI
\end{lstlisting}

\begin{peringatanbox}
\vspace{1.1em}
\asm{LOOP} mengubah \reg{CX}. Bila \reg{CX} sedang dipakai untuk
keperluan lain, simpan nilainya terlebih dahulu atau gunakan
pasangan \asm{DEC} dan \asm{JNZ} dengan register lain. Kesalahan
paling sering pada perulangan bersarang adalah lupa memulihkan
pencacah luar.
\end{peringatanbox}

\begin{infobox}
\vspace{1.1em}
Perulangan \asm{LOOP} dan lompatan bersyarat hanya mengubah alur
eksekusi. Keduanya tidak mengubah isi array atau variabel kecuali
instruksi di dalam badan perulangan memang melakukannya.
\end{infobox}
