\section{Rangkuman}
\label{sec:rangkuman-bab16}

Pada bab ini telah dibahas:

\begin{itemize}
    \item Kesalahan program dibagi menjadi kesalahan sintaks,
          kesalahan logika, dan program yang berhenti
          (\eng{hang}).

    \item Kesalahan sintaks dilaporkan assembler. Kesalahan logika
          dan \eng{hang} harus dicari dengan \eng{debugger}.

    \item DEBUG menyediakan perintah \file{R} untuk register,
          \file{T} untuk satu instruksi, \file{P} untuk melewati
          prosedur, \file{D} untuk memeriksa memori, dan \file{G}
          untuk menjalankan sampai alamat tertentu.

    \item emu8086 menyediakan \eng{single step} serta jendela
          register, \eng{flag}, dan memori. Turbo Debugger
          menyediakan tampilan register, \eng{flag}, memori, dan
          stack.

    \item Penelusuran per instruksi mencatat perubahan register dan
          \eng{flag} pada setiap langkah. Pola perubahan inilah yang
          menunjukkan letak kesalahan.

    \item Perulangan tak berujung terjadi bila pencacah tidak pernah
          mencapai nilai berhenti. Pada \file{bug-loop.asm},
          \lstasm|INC CX| membuat \reg{CX} tidak pernah nol.

    \item Stack tidak seimbang terjadi bila jumlah \asm{PUSH} dan
          \asm{POP} berbeda. Pada \file{bug-stack.asm}, satu
          \asm{POP} yang hilang membuat \asm{RET} mengambil alamat
          yang salah.

    \item Debugging dilakukan secara sistematis: reproduksi,
          isolasi, hipotesis, uji dengan \eng{trace}, perbaikan, dan
          verifikasi.
\end{itemize}

\begin{checklistbox}
\vspace{1.1em}
Tandai setiap butir yang sudah Anda kuasai.

\begin{itemize}
    \item[\checkbox] Saya dapat membedakan kesalahan sintaks, logika,
          dan \eng{hang}.
    \item[\checkbox] Saya dapat menggunakan perintah DEBUG untuk
          menelusuri program.
    \item[\checkbox] Saya dapat mencatat perubahan register dan
          \eng{flag}.
    \item[\checkbox] Saya dapat memeriksa memori dan stack dengan
          \eng{dump}.
    \item[\checkbox] Saya dapat menemukan penyebab perulangan tak
          berujung.
    \item[\checkbox] Saya dapat menemukan ketidakseimbangan
          \asm{PUSH}/\asm{POP}.
    \item[\checkbox] Saya dapat memperbaiki dan memverifikasi hasil
          perbaikan.
\end{itemize}

\vspace{0.4em}
Bila masih ada butir yang belum bertanda, ulangi bagian yang
bersesuaian sebelum melanjutkan ke bab berikutnya.
\end{checklistbox}
