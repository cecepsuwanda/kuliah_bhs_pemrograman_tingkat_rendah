\section{Contoh Penilaian Proyek Akhir}
\label{sec:contoh-bab17}

Agar rubrik pada Tabel~\ref{tab:rubrik-proyek} tidak abstrak, berikut
dua contoh penerapannya.

\subsection{Contoh 1: Proyek Kalkulator}

Mahasiswa mengerjakan pilihan kalkulator sederhana. Proyek memuat:

\begin{itemize}
    \item prosedur \code{BacaAngka} yang membaca masukan dengan
          \code{INT 21h} fungsi \hex{0A} dan mengubahnya menjadi
          nilai biner;
    \item prosedur \code{Hitung} yang menerima dua parameter melalui
          stack dan mengembalikan hasil pada \reg{AX};
    \item prosedur \code{TulisAngka} yang mengubah hasil menjadi
          digit desimal dan mencetaknya;
    \item penanganan pembagian dengan nol.
\end{itemize}

\subsection{Contoh 2: Proyek Pengolah Array dan String}

Mahasiswa mengerjakan pilihan pengolah array/string. Proyek memuat:

\begin{itemize}
    \item prosedur \code{JumlahArray} yang menerima alamat dan cacah
          elemen melalui stack;
    \item prosedur \code{SalinString} yang menyalin string sampai
          penanda \code{'\$'};
    \item prosedur \code{TulisDesimal} untuk mencetak hasil;
    \item pengujian dengan array kosong, satu elemen, dan banyak
          elemen.
\end{itemize}
