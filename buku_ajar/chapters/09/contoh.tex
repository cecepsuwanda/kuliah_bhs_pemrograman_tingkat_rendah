\section{Contoh}
\label{sec:contoh-bab9}

Dua contoh berikut memperlihatkan pemakaian interupsi DOS dan BIOS.
Contoh pertama memakai \code{INT 21h} untuk mencetak pertanyaan dan
membaca nama. Contoh kedua memakai \code{INT 10h} untuk mengatur
layar dan menulis teks berwarna.

\subsection{Contoh 1: Membaca Nama dengan INT 21h}

Program pada Kode~\ref{lst:input-nama} mencetak pertanyaan,
membaca nama dengan fungsi \hex{0A}, lalu menyapa pengguna.

\lstinputlisting[
    language=MASM,
    caption={Program \file{input-nama.asm} membaca nama dengan
    \code{INT 21h} fungsi \hex{0A}.},
    label={lst:input-nama}
]{\CodeDir/input-nama.asm}

Bagian penting program tersebut:

\begin{itemize}
    \item \lstasm|MOV AH, 09h| dan \lstasm|LEA DX, tanya| mencetak
          pertanyaan. String diakhiri \code{'\$'}.
    \item \lstasm|MOV AH, 0Ah| dan \lstasm|LEA DX, nama| membaca
          masukan ke penyangga \code{nama}.
    \item Byte 0 penyangga berisi kapasitas 20, byte 1 diisi DOS
          dengan jumlah karakter, dan byte 2 dan seterusnya berisi
          nama.
    \item Setelah masukan, program menghitung akhir nama dengan
          \lstasm|MOV BL, [SI+1]|, lalu menulis \code{'\$'} pada
          posisi setelah karakter terakhir.
    \item \lstasm|LEA DX, nama+2| menunjuk karakter pertama nama
          sehingga nama dapat dicetak dengan fungsi \hex{09}.
    \item \lstasm|MOV AH, 4Ch| dan \lstasm|INT 21h| mengakhiri
          program.
\end{itemize}

Keluaran program tampak pada Kode~\ref{lst:keluaran-input}.

\begin{lstlisting}[
    style=sessiongaya,
    caption={Keluaran program \file{input-nama.asm}.},
    label={lst:keluaran-input}
]
Siapa nama Anda? Budi
Halo, Budi! Selamat belajar assembly.
\end{lstlisting}

\subsection{Contoh 2: Menulis Teks Berwarna dengan INT 10h}

Program pada Kode~\ref{lst:warna-layar} memakai layanan video BIOS
untuk menetapkan mode teks, menulis judul berwarna, memindahkan
kursor, dan menulis garis.

\lstinputlisting[
    language=MASM,
    caption={Program \file{warna-layar.asm} memakai \code{INT 10h}
    untuk menulis teks berwarna.},
    label={lst:warna-layar}
]{\CodeDir/warna-layar.asm}

Register yang dipakai pada setiap pemanggilan \code{INT 10h}
dirangkum pada Tabel~\ref{tab:register-warna}.

\begin{table}[H]
    \centering
    \caption{Register pada pemanggilan \code{INT 10h} di
    \file{warna-layar.asm}.}
    \label{tab:register-warna}
    \small
    \begin{tabular}{@{}p{1.4cm}p{2.8cm}p{7.6cm}@{}}
        \toprule
        \textbf{AH} & \textbf{Fungsi} & \textbf{Register yang diisi} \\
        \midrule
        \hex{00} & Set mode & \reg{AL} = \hex{03} (teks 80$\times$25
        berwarna) \\
        \addlinespace
        \hex{13} & Tulis string & \reg{AL} = \hex{01},
        \reg{BH} = 0, \reg{BL} = \hex{0E}, \reg{CX} = panjang,
        \reg{DH} = 5, \reg{DL} = 10, \reg{ES}:\reg{BP} = string \\
        \addlinespace
        \hex{02} & Set kursor & \reg{BH} = 0, \reg{DH} = 7,
        \reg{DL} = 10 \\
        \addlinespace
        \hex{09} & Tulis karakter & \reg{AL} = \code{'='},
        \reg{BL} = \hex{0C}, \reg{CX} = panjang, \reg{BH} = 0 \\
        \bottomrule
    \end{tabular}
\end{table}

Tampilan yang dihasilkan berupa judul kuning pada baris 5 kolom 10
dan garis merah pada baris 7 kolom 10. Warna tidak terlihat pada
keluaran teks biasa karena atribut warna disimpan pada byte atribut
layar, bukan pada karakter.

\begin{infobox}
\vspace{1.1em}
Fungsi \hex{13} memakai \reg{ES}:\reg{BP} sebagai alamat string,
bukan \reg{DS}:\reg{DX} seperti fungsi \hex{09} DOS. Karena itu,
program terlebih dahulu menyamakan \reg{ES} dengan \reg{DS} agar
string pada segmen data dapat ditemukan.
\end{infobox}
