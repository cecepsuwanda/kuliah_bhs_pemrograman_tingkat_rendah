\section{Rangkuman}
\label{sec:rangkuman-bab9}

Pada bab ini telah dibahas:

\begin{itemize}
    \item Interupsi adalah permintaan kepada prosesor untuk
          menghentikan sementara pekerjaan yang sedang berjalan,
          melayani suatu keperluan, lalu kembali ke pekerjaan semula.

    \item Interupsi perangkat keras berasal dari perangkat luar,
          sedangkan interupsi perangkat lunak berasal dari instruksi
          \code{INT n}.

    \item 8086 menyediakan 256 nomor interupsi. Nomor \hex{00}--
          \hex{1F} disediakan BIOS, sedangkan \hex{20}--\hex{FF}
          disediakan DOS.

    \item Tabel vektor interupsi berada pada alamat \hex{00000}--
          \hex{003FF}, berukuran 1 KB, dan terdiri atas 256 entri.
          Setiap entri berisi offset dan segmen handler.

    \item Instruksi \code{INT n} menyimpan \reg{FLAGS}, \reg{CS},
          dan \reg{IP}, lalu memuat alamat handler dari vektor.
          \code{IRET} memulihkan ketiganya.

    \item \code{INT 10h} menyediakan layanan video: menetapkan mode,
          memindahkan kursor, menulis karakter, dan menulis string
          berwarna.

    \item \code{INT 16h} menyediakan layanan \eng{keyboard}: membaca
          tombol, memeriksa ketersediaan tombol, dan membaca status
          tombol khusus.

    \item \code{INT 21h} menyediakan layanan DOS: membaca karakter,
          mencetak karakter, mencetak string, membaca string
          berpenyangga, dan mengakhiri program.

    \item \code{INT 20h} mengakhiri program \file{.COM}, sedangkan
          \code{INT 21h} fungsi \hex{4C} mengakhiri program dengan
          kode keluar pada \reg{AL}.
\end{itemize}

\begin{checklistbox}
\vspace{1.1em}
Tandai setiap butir yang sudah Anda kuasai.

\begin{itemize}
    \item[\checkbox] Saya dapat menjelaskan interupsi perangkat keras
          dan perangkat lunak.
    \item[\checkbox] Saya dapat menjelaskan tabel vektor interupsi
          dan menghitung alamat entrinya.
    \item[\checkbox] Saya dapat menjelaskan alur \code{INT} dan
          \code{IRET}.
    \item[\checkbox] Saya dapat menggunakan \code{INT 10h} untuk
          layanan video.
    \item[\checkbox] Saya dapat menggunakan \code{INT 16h} untuk
          layanan keyboard.
    \item[\checkbox] Saya dapat menggunakan \code{INT 21h} untuk
          masukan dan keluaran.
    \item[\checkbox] Saya dapat membedakan \code{INT 20h} dan
          \code{INT 21h} fungsi \hex{4C}.
\end{itemize}

\vspace{0.4em}
Bila masih ada butir yang belum bertanda, ulangi bagian yang
bersesuaian sebelum melanjutkan ke bab berikutnya.
\end{checklistbox}
