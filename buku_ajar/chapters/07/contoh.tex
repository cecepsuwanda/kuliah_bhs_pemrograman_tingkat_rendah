\section{Contoh}
\label{sec:contoh-bab7}

Dua contoh berikut memperlihatkan kerangka program dan direktif data.
Contoh pertama adalah program \file{.EXE} yang mencetak teks. Contoh
kedua memperlihatkan bagaimana beberapa direktif data menyusun isi
segmen data.

\subsection{Contoh 1: Program Pertama}

Program pada Kode~\ref{lst:hello} adalah program assembly pertama
yang biasa dipakai: mencetak satu baris teks ke layar.

\lstinputlisting[
    language=MASM,
    caption={Program \file{hello.asm} mencetak teks ke layar.},
    label={lst:hello}
]{\CodeDir/hello.asm}

Bagian penting program tersebut adalah sebagai berikut.

\begin{itemize}
    \item \dir{.MODEL SMALL} menetapkan satu segmen kode dan satu
          segmen data.
    \item \dir{.STACK 100h} menyediakan 256 byte ruang \eng{stack}.
    \item \dir{.DATA} membuka segmen data. Variabel \code{pesan}
          berisi string yang diakhiri \code{0Dh}, \code{0Ah}, dan
          \code{'\$'}.
    \item \dir{.CODE} membuka segmen kode, lalu label \code{START:}
          menandai instruksi pertama.
    \item \lstasm|MOV AX, @DATA| dan \lstasm|MOV DS, AX|
          menginisialisasi \reg{DS} agar variabel dapat diakses.
    \item \lstasm|MOV AH, 09h|, \lstasm|LEA DX, pesan|, dan
          \lstasm|INT 21h| mencetak string.
    \item \lstasm|MOV AH, 4Ch| dan \lstasm|INT 21h| mengakhiri
          program.
    \item \dir{END START} menutup berkas dan menetapkan label
          \code{START} sebagai titik masuk.
\end{itemize}

Setelah dirakit dan di-link, program menghasilkan keluaran seperti
pada Kode~\ref{lst:keluaran-hello}.

\begin{lstlisting}[
    style=sessiongaya,
    caption={Keluaran program \file{hello.asm}.},
    label={lst:keluaran-hello}
]
Halo, dunia!
\end{lstlisting}

\subsection{Contoh 2: Direktif Data}

Program pada Kode~\ref{lst:direktif-data} mendemonstrasikan direktif
\dir{DB}, \dir{DW}, \dir{DD}, \dir{EQU}, dan \dir{DUP}.

\lstinputlisting[
    language=MASM,
    caption={Program \file{direktif-data.asm} mendemonstrasikan
    direktif data.},
    label={lst:direktif-data}
]{\CodeDir/direktif-data.asm}

Penjelasan bagian data:

\begin{itemize}
    \item \code{sapaan DB 'Halo, assembly!', 0Dh, 0Ah, '\$'}
          menyimpan string sebagai byte-byte berurutan.
    \item \code{panjang EQU \$ - sapaan} menghitung panjang string
          dari selisih posisi sekarang dengan awal label.
    \item \code{kata DW 4241h, 4443h} menyimpan dua kata. Kata
          pertama berisi byte \hex{41}, \hex{42} (karakter
          \code{A} dan \code{B}); kata kedua berisi \hex{43},
          \hex{44} (karakter \code{C} dan \code{D}).
    \item \code{nilai DD 12345678h} menyediakan ruang empat byte.
    \item \code{bintang DB 4 DUP('*')} mengulang karakter bintang
          empat kali.
    \item \code{buffer DB 8 DUP(?)} menyediakan delapan byte tanpa
          nilai awal.
\end{itemize}

Program mencetak string sapaan, lalu empat karakter dari data
\code{kata}, kemudian empat bintang. Keluarannya tampak pada
Kode~\ref{lst:keluaran-direktif}.

\begin{lstlisting}[
    style=sessiongaya,
    caption={Keluaran program \file{direktif-data.asm}.},
    label={lst:keluaran-direktif}
]
Halo, assembly!
ABCD****
\end{lstlisting}

Contoh ini menunjukkan bahwa direktif data hanya menyusun isi
memori. Instruksi yang mencetak data tetap ditulis pada segmen kode.
